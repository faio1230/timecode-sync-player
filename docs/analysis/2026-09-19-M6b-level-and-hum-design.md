# M6-b 設計: レベル×ノイズの組み合わせとハム（2026-09-19）

**背景（利用者の現場情報）**: 「レコーダーからそのまま抜くこともある。回線が足りない場合は分配する（レベルが小さくなる可能性）。
基本的にはアナログの回線」。M6 は**レベルとノイズを別々に**振っただけなので、現場の「レベル低下＋アナログノイズ」を直接は見ていない。
また M6 のノイズは広帯域で、現場のアナログ回線で乗るのは**ハム**が主。

**目的**:
1. **レベル×ノイズ**: SNR が同じなら、信号レベルが違ってもデコード率と崖は同じか。
   - 同じ → 支配量は SNR ひとつ。警告も SNR（または crest factor）だけ見ればよい
   - 違う → レベルに独立した効きがある。別の警告が要る
2. **ハム**: 同じ SNR で、広帯域ノイズと 50/60Hz ハム（3 次・5 次倍音入り）の崖の位置が違うか。
   - ハムの方が壊れにくい / 壊れやすい のどちらかを数字で出す
3. crest factor 警告の設計は **M6-b の結果を見てから**（ハムで crest が上がるかを先に確認）。

**実機は同期担当（世代チェック V3）の後**。実機不要の準備（ハーネス拡張）は先に進めてよい。

---

## 1. 条件 H1: レベル × ノイズ

**振り方**（同一 SNR を 2 レベルで対にする）:

| レベル | 信号振幅 | SNR12 | SNR5.0 | SNR4.5 |
| --- | ---: | --- | --- | --- |
| −6 dBFS | 0.501 | ○ | ○（peak 0.989） | ×（peak 1.018 → 経路の正規化が入る） |
| −20 dBFS | 0.100 | ○ | ○ | ○ |
| −40 dBFS | 0.010 | - | ○ | ○ |

- プラン案: clean / (−6, SNR12) / (−20, SNR12) / (−6, SNR5.0) / (−20, SNR5.0) / (−40, SNR5.0) / (−20, SNR4.5) / (−40, SNR4.5)
  = 8 レベル。peak > 1 になる組み合わせは使わない（経路のピーク正規化を避ける）。
- **予想**: SNR が支配なら、SNR12 の 2 レベルは両方 100%、SNR5.0 は両方 100%、SNR4.5 は両方 0〜1%。
  レベル間で decode%/clean% と誤差分布が一致するかを見る。
- **一致しなかった場合**: 「信号が小さいほど壊れやすい/壊れにくい」をレベルごとに数字で示す（次の警告設計の材料）。

## 2. 条件 H2: ハム（50Hz / 60Hz + 3 次・5 次）

**生成式**（テスト側の波形後加工。振幅は SNR から決める）:

```
hum(t) = A_h × [ sin(2π f t) + (1/3) sin(6π f t) + (1/5) sin(10π f t) ]   (f = 50 or 60 Hz)
```

- 倍音込みの hum RMS = A_h × sqrt((1/2)(1 + 1/9 + 1/25)) = **0.75865 × A_h**。
- `A_h = A_signal × 10^(−SNR/20) / 0.75865`（A_signal は矩形波振幅 = 信号 RMS）。
- 位相は 0 固定（決定的）。現場の位相は任意なので、必要なら run で位相を変えて感度を見る（任意）。
- 生成手順は既存の `DirtyLtcSignal` に `ApplyHum` を追加するだけ（ドロップアウト/リサンプルと同じ位置）。

**レベル案**（clean + SNR 12 / 6 / 3 / 0 の 4 点）:
- M6 の広帯域ノイズは 5.0dB まで正常、4.5dB で崩壊。ハムはこれより浅い/深い可能性があるので、
  **12 / 6 / 3 / 0 dB** を振って崖を探す。0dB でも壊れなければ −3 / −6 を追加（1 本追加）。
- 50Hz と 60Hz は別 run（1 条件ずつ）。
- **比較用のアンカー**: 広帯域ノイズは既存 M6 の 6dB（100%）と 4.5dB（0.8%）をそのまま使う。

**予想**（利用者）: ゼロクロス判定に効くのは高域なので、**ハムの方が耐性が高い**はず。ただし当てにしない。

## 5. 分析と報告

- 既存の形式（clean 実測 → 各レベル、Δclean、崖の位置と落ち方）で報告。
- **H1**: SNR ごとにレベル違いの decode%/clean% と誤差 p95 を並べ、一致/不一致を数字で示す。
- **H2**: 50/60Hz の崖の位置を広帯域ノイズ（5.0/4.5dB）と並べる。**crest** もレベルごとに併記（警告設計の材料）。
- 壊れる点が見つからなければ「試した範囲は〜まで」を明示。

## 6. リスク

| リスク | 対処 |
| --- | --- |
| ピーク > 1 で経路の正規化が入る | H1 は peak ≤ 1 の組み合わせだけにする（表の ○ のみ） |
| ハムの位相が固定 | SNR 支配なら位相依存は小さい。必要なら位相違いで 1 本追加 |
| ハムで 0dB まで壊れない | −3 / −6dB を追加（合計 +3 分） |
| crest がハムで上がらない | その場合は crest 警告は広帯域ノイズ限定と報告（設計判断の材料） |
| 現場の実レベル/ハム量の実測が無い | 試した範囲を明示。距離の定量は利用者側の実測待ち |

## 7. 順序

1. 同期担当の V3（世代チェック）→ 実機が空いたら **H1（2 本）→ H2-50（2 本）→ H2-60（2 本）**
2. 結果を見て、必要なら低 SNR/低レベルを追加
3. **その後**に crest factor 警告の設計（crest と SNR の表、しきい値、誤検出、2 秒窓の遅れ）
