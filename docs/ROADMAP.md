# 開発ロードマップ：v0.5.x〜v0.8.0

更新日: 2026-09-27（2026-09-22 版を、v0.6.0 を ProRes の GPU 復号に改め、UI 刷新の詳細を UI/UX の作業ブランチへ切り出して更新）

本書は製品全体の版の並びと、各版で確定する事項をまとめたロードマップです。
記載する機能は実装済みではありません（済みと明記したものを除く）。リリース日・工数・対応ハードウェアの範囲は未定です。

## 1. 全体方針

現行版を現場でトラブルなく使える状態にすることを優先し、その安定性を土台に次の機能を段階的に追加します。
**安定版（Latest）は v0.5.x の最新**とし、v0.6 以降は検証が済むまでプレリリースとして公開します。
UI 刷新は現行版の安定化と ProRes 対応の後に進める版として扱い、作業は UI/UX の作業ブランチで進めます。

| 段階 | 目的 | 主な内容 | 状態 |
|---|---|---|---|
| v0.5.0 | HAP の GPU デコードに対応する | HAP 素材の GPU デコード対応と、既存の LTC 同期・出力経路への統合 | 公開済み（2026-09-24） |
| v0.5.1〜v0.5.4 | 現行版を安定版にする | 同期の一時状態の整理、着地の遅延の解消、シーク経路の門の統合、既知の不具合の解消。v0.5.4 を安定版（Latest）にする | v0.5.3 公開済み、v0.5.4 作業中 |
| v0.6.0 | ProRes の GPU デコードに対応する | GStreamer プラグイン gst-prores-d3d11 の同梱（NVIDIA で検証・既定有効、他ベンダーは既定で CPU デコード、設定で切替）、スクリプトの PowerShell 7 化 | 計画済み（[release-0.6-plan.md](release-0.6-plan.md)） |
| v0.7.0 | 仕込み環境を刷新する | 新しい UI 構成、独立した素材チェック、タイムライン編集、基本のフェード IN／OUT | 設計中（UI/UX の作業ブランチ） |
| v0.8.0 | トランジションを拡張可能にする | 2 映像の同時再生・先読み、HLSL によるカスタムトランジションの作成・読み込み | 構想 |

全バージョンを通して、UI 操作による本番出力の停止・瞬間的なフリーズ・同期遅延を防ぐことを設計と検証の条件にします。
GPU 描画のスレッド分離だけで達成したとは判断せず、同期・再生制御の UI 依存と、GPU・ディスクなどの共有負荷も確認します。

## 2. v0.5.x：現行版の安定化（v0.5.4 で安定版）

- v0.5.0: HAP の GPU デコード（公開済み）。
- v0.5.1〜v0.5.3: 同期の一時状態の整理と寿命の修正、ランスルーで保持した後のジャンプの着地の遅延の解消（公開済み、プレリリース）。
- v0.5.4: シーク経路の門の統合（着地の判定を配信フレームの世代と位置で 1 つにする）、プロジェクト復元の不具合、既知のエラーの解消。**安定版（Latest）として公開する版。**
- 合否は固定の一式（標準シナリオ・連続追従・トラック切替、RTX）と検証機の実素材で判定し、既知の制限に残すのは推奨素材の範囲外か試験専用の条件だけとします。

## 3. v0.6.0：ProRes の GPU デコード

- 対象: gst-prores-d3d11（`proresd3d11dec`、D3D11 Compute Shader、LGPL-2.1）をタグ付きリリースのバイナリとして同梱し、`prores-gpu` の復号プロファイルを追加する。
- 既定: NVIDIA のアダプタでだけ GPU デコードを既定で有効にし、他のベンダーは既定で CPU デコード（未検証のためサポート対象外）。設定 `proResGpu`（自動／有効／無効）と UI の 3 択で切り替える。ロード成功の判定を満たさないときは CPU デコードへ戻る。
- あわせて、スクリプトを PowerShell 7 に寄せる（5.1 向けの回避を外す）。
- 完了条件と決定事項は [release-0.6-plan.md](release-0.6-plan.md)。

## 4. v0.7.0 以降：UI 刷新とトランジション

仕込み環境の刷新（新しい UI 構成、独立した素材チェック、タイムラインの直接操作、基本のフェード）と、HLSL によるカスタムトランジションの詳細は、
UI/UX の作業ブランチ（`ui-ux-docs`、実装は `codex/ui-ux-demo`）の `docs/UI-ROADMAP.md` と `docs/UI-UX-DESIGN.md` にまとめています。
main には版の公開時に統合します。

## 5. 実装前に確定する事項

1. v0.6.0 で同梱する ProRes プラグインの版と、GPU デコードを既定で有効にするアダプタの範囲、CPU デコードへ戻る条件。
2. 各バージョンの対象素材・解像度・GPUと、同期誤差・出力間隔などの合格基準。
3. 本番中の配置・トリミング・素材差し替えの反映時点。再生中の素材差し替えまで含めるか。
4. v0.7.0 のクリップ重複時の規則と、v0.8.0 でトランジション区間を作る方法。
5. トランジション用の素材の余白不足、信号断、Gap、Freeze、終端での動作。
6. 素材チェックの音声出力、黒へのフェードと透過出力の関係。
7. 既存プロジェクトとの互換性、追加設定の既定値、HLSLファイルの持ち運び方。
