## 4. 構文・空振り

**構文と文字**: pwsh の `[System.Management.Automation.Language.Parser]::ParseFile` で 33 本すべてエラー 0。
同じ検査で、全バイトを走査して CR・LF 以外の制御文字 0（タブも 0）、裸の LF 0、裸の CR 0（すべて CRLF）。`git ls-files --eol` もすべて `w/crlf`。
途中で Git Bash の `sed -i` が全 33 本の CR を落としたので、バイト単位で CRLF に戻してからコミットした（コミットの中身は CRLF。index は autocrlf で LF）。
