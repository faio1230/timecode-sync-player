# TimecodeSyncPlayer v0.4.3

v0.4.2 までの LTC 同期の欠陥（Single の終端で次トラックへ進む、ジャンプで入る Freeze、保持 LTC の停止/ランスルー、ジャンプ時の一瞬の黒、長 GOP の一時停止シーク、シーク直後の古いフレーム、ハイブリッド GPU での合成の完了待ち）を修正します。

### 修正

- Single + 同期 ON で、LTC がアクティブトラックの尺以上になると終端シーク後に次トラックへ自動前進していた。終端で停止する（D20）
- Single モードで、LTC がトラックの `MediaOut` を超えると尺（媒体の長さ）までシークし、`MediaOut` の外へ着地していた。LTC → 素材位置の写像と終端の clamp を `MediaIn` / `MediaOut` にし、`MediaOut` 未設定は尺にする。終端静止も `MediaOut` 基準（D29）
- Continue + Freeze で、ジャンプで入った Freeze 領域が前トラックの最終フレームにならなかった（ジャンプ時点の絵を凍結、または黒）。ギャップ進入時は直前トラックの最終フレームを位置（PTS ±2 フレーム）で確定し、一致しなければ最大 2 回再シークする（D21、D21-b）
- 最初のトラックより前（先頭オフセット）が黒になっていた。最初のトラックの冒頭フレームを表示する（D22）
- ジャンプ（シーク・トラック切替）で一瞬黒が挟まっていた（D26、D26-b）
- 保持 LTC（同じ値の連送）を「タイムコード停止」として信号断と同じ扱いにした。停止モードは保持値で一時停止、ランスルーは走り続け、復帰で再同期する。保持損失からの復帰は Jump 1 枚で成立させ、停止時の着地目標は保持している値にする（D27、D27-b、D27-c、D27-d）
- 長 GOP（キーフレーム 10 秒間隔など）の一時停止シークで、ポンプ期限 500ms を復号が超えてフレームが来ず位置が動かなかった。期限を「最初のフレーム到着まで、上限 4000ms（`TCS_PUMP_BUDGET_MS` で可変）」にし、超過は復号進捗つきの警告にする。step も同じポンプを使う（D24）
- シーク直後にリースしたフレームが「位置（PTS）は目標・画素はシーク前」になることがあった。シーク前サンプルを flush 境界で新世代から排除し、共有フェンス値をプレイヤー寿命で単調にした（D25）。fence 未完了のリースは返却せず保持して次 tick で再確認し、実際に描いたフレームだけを最終フレームの確定に使う（D25-b）。一時停止中の位置は最新の映像フレーム PTS を返す（D25-c）
- ハイブリッド GPU で 4K VP9 の一時停止シーク後に合成の GPU 完了待ちが 100ms を超えると、再生が「利用不可」のまま止まっていた。完了待ちは 100ms スライスで打ち切って今 tick を skip し、面・リース・ソース画像は保留して次 tick 以降に回収する。恒久停止はデバイス消失か連続 3 秒の未完了のときだけにする（D28）
- 保持 LTC から新しい値へのジャンプ直後、音声の取り込みが一時的に滞ると次のフレームがまとめて届き、未確認 Jump の確認が受信間隔（壁時計）で外れて保留を捨て、停止モードで新しい保持値に着地できなかった。確認はフレーム終端（サンプル位置由来）の差で判定し、使えないときだけ壁時計にする（D31）
- 停止モードで保持 LTC の値が変わっても、再生位置が前の値のまま留まっていた。保持損失中に保持値が着地済みの値から半フレーム超変わったら、停止モードは新しい値へ 1 回着地し、ランスルーは変化ごとに 1 回適用する（D31-b）
- （テスト）検証シナリオ C-1 の着地判定が固定の目標だったため、ランスルーで動画が進み着地に時間がかかる実素材では判定が外れていた。着地を区間 [着地目標 − 0.3, 着地目標 + 経過秒 + 0.3 + 1 フレーム]（停止モードは ±0.3 固定）で見て、着地後 0.5 秒の追従をジャーナルに残す

### 変更

- 合成の Held を、リングの面ではなく合成側が所有する直前キャンバスの複製にした。黒はギャップが Black のときだけ描く（D26）
- 一時停止中の `get_time_pos` は、ポンプ完了後は最新の配信済み映像フレームの stream time PTS を返す（再生中は従来のパイプライン位置）（D25-c）
- GPU 完了待ちの期限超過は fault ではなく tick の skip と保留にし、`Playback unavailable` へ落とす条件をデバイス消失か連続 3 秒の未完了に限定した（D28）

### 追加

- 一時停止シークのポンプ期限の上書き `TCS_PUMP_BUDGET_MS`（1〜60000ms、既定 4000ms）（D24）
- 出力トレースに `compose.fencePending`（保留リースの start / complete / timeout / release）（D25-b）
- E2E に保持 LTC の停止/ランスルー（R-1〜R-4）、ジャンプ中の黒検出（C-1 / C-2）、Freeze の最終フレーム（F-1〜F-5）、ギャップ（G-1〜G-6）を追加

## 既知の制限

- 長 GOP 素材（キーフレーム間隔 10 秒など）では、再生中の accurate シークがキーフレームから目標まで復号するため、ジャンプの着地が 1〜3 秒遅れることがある（60fps H.264、キーフレーム間隔 10 秒の実素材で確認）。現場向けの推奨: キーフレーム間隔 1〜2 秒（60fps なら `-g 60〜120`）で書き出す。一時停止中のシークは D24 のポンプ期限により最大 4 秒まで待つ（`TCS_PUMP_BUDGET_MS`）
