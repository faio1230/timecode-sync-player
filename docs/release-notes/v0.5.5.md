# TimecodeSyncPlayer v0.5.5

**v0.5 系の安定版（Latest）です。** v0.5.4 の不具合を 1 件直しました。ほかの内容・既知の制限・運用の推奨は v0.5.4 と同じです（[v0.5.4 のリリースノート](v0.5.4.md)）。

v0.5.4 からの移行の注意: 無し（設定・プロジェクトの形式は変わりません）。

### 修正

- **Single モード・RunThrough で、LTC がクリップの外で保持されたまま（送出が止まったまま）トラックを読み込む・切り替えると、クリップの出口を越えて再生が続き、クリップの外の絵が出ることがあった。**
  主に 50/60fps の映像で起き、30fps 以下でも UI が一瞬止まったときに起こりうる。v0.5.4 以前から。
  読み込みの後、止まった LTC の位置への合わせ（入口の合わせ）はクリップの出口へシークするが、その記録を出口で止める判定（境界の保持）に残していなかった。
  そのため、出口で止まるのは、判定の瞬間に再生位置が出口の ±2 フレーム以内にあったときだけだった（60fps では約 33ms の間）。
  入口の合わせで出口へ収めたシークを境界の保持の記録に残し、次の判定で必ず出口で止まるようにした

### 既知の不具合（v0.6.1 で修正）

- LTC の信号が乱れた直後に、位置を合わせ直すシークが続けて出て、4K 60p の素材で最大 0.6 秒ほど映像が止まることがある。v0.5.4 と同じ。v0.6.1 で修正
