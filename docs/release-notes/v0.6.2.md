# TimecodeSyncPlayer v0.6.2

**安定版（Latest）です。** ProRes の GPU 復号のプラグインを更新しました。ほかの内容・既知の制限・運用の推奨は v0.6.1 と同じです（[v0.6.1 のリリースノート](https://github.com/faio1230/timecode-sync-player/releases/tag/v0.6.1)）。

v0.6.1 からの移行の注意: 無し（設定・プロジェクトの形式は変わりません）。

### 変更

- **ProRes の GPU 復号のプラグイン gst-prores-d3d11 を v0.2.1 から v0.2.3 に更新しました。** v0.2.2 と v0.2.3 の変更は、GPU の処理が追いつかないときに、締切を過ぎたフレームを復号の前に捨てる改善（QoS）と、その設定の不備の修正だけです。この仕組みは再生の出口が QoS を返すときに働くもので、TimecodeSyncPlayer の再生経路は QoS を使っていないため、**再生の挙動は変わりません**（開発機で確認: 出口の設定と、再生中に QoS のイベントが流れないこと）。画質・対応する形式・シェーダーは v0.2.1 と同じです

### 既知の不具合

- 推奨素材の範囲内で既知の不具合は 0 件です（v0.6.1 と同じ）

### 既知の間欠（v0.6.1 のノートの一覧に加えて）

- LTC の信号が乱れて止まったと判定されたとき、RunThrough では止まった位置へ 1 回合わせ直し、その着地で映像が 0.5 秒前後止まることがある（規則どおりの反応。検証機の試験経路の乱れで 1 回、0.517 秒）
