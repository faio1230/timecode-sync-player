# ERYTHEIA v0.6.7

**試験版（Pre-release）です。本番には安定版 v0.6.6（Latest）を使ってください。**
この版から、アプリの名前を「ERYTHEIA」にしました（v0.6.6までは「TimecodeSyncPlayer」）。exe・インストーラー・配布物・設定の保存先・ログ・Spoutの既定の送信名・プロジェクトの拡張子・環境変数の名前が変わります。v0.6.xの間は、旧の名前の設定・プロジェクト・環境変数も読みます。あわせて操作画面の配色と配置を改め、プレイリストの一覧を一覧の中でスクロールするようにしました。同期の規則・ゲート・定数はv0.6.6と同じです。ほかの内容・既知の制限・運用の推奨はv0.6.6と同じです（[v0.6.6のリリースノート](https://github.com/faio1230/timecode-sync-player/releases/tag/v0.6.6)、[v0.6.1のリリースノート](https://github.com/faio1230/timecode-sync-player/releases/tag/v0.6.1)）。

### v0.6.6からの移行の注意

- **設定**: 保存先が`%LOCALAPPDATA%\ERYTHEIA\settings.json`になりました。新しい場所に設定が無く、v0.6.6までの`%LOCALAPPDATA%\TimecodeSyncPlayer\settings.json`があるときだけ、最初の起動で新しい場所へ写します。元のファイルは消さないので、v0.6.6に戻してもそのまま使えます。写すのに失敗したときは既定の設定で起動し、ログにWarningを1行出します。その後の保存で新しい場所に設定ができるので、以後は写しません。旧のファイルは残るので、手で写せます
- **Spoutの送信名**: 既定の送信名が`TimecodeSyncPlayer`から`ERYTHEIA`に変わりました。受け側で旧の名前を選んでいる場合は、受け側で選び直すか、環境変数`ERYTHEIA_SPOUT_NAME=TimecodeSyncPlayer`を付けて旧の名前で送ってください
- **環境変数**: 名前を`TIMECODE_SYNC_PLAYER_*`・`TCS_*`から`ERYTHEIA_*`に変えました（後ろの部分は同じ。例: `TCS_GOP_SCAN`→`ERYTHEIA_GOP_SCAN`）。v0.6.xの間は、新しい名前が無ければ旧の名前も読み、変数ごとにWarningをログに1行出します。両方があれば新しい名前を使います。v0.7.0からは旧の名前を読みません
- **プロジェクト**: 保存の既定の拡張子が`.erytheia`になりました。v0.6.6までの`.tsp`も開けます。中身の形式は同じです
- **ログ**: ログのファイルの名前が`erytheia-YYYYMMDD.log`（アプリ）と`erytheia-gst-YYYYMMDD.log`（再生のエンジン）になりました。置き場はこれまでどおり、アプリのフォルダの`logs`です

### インストール先

新しく入れると`%LOCALAPPDATA%\Programs\ERYTHEIA`に入ります。インストーラーはv0.6.6までと同じアプリとして扱うので、v0.6.6以前が入っているPCでは上書きの更新になり、インストール先は前の場所（`%LOCALAPPDATA%\Programs\TimecodeSyncPlayer`）のままです。上書きでは、旧の名前の実行ファイルと関連のファイル（dll・deps.json・runtimeconfig.json）とshim（`tcs_gstreamer.dll`）が消え、スタートメニューの項目はERYTHEIAの1つになります。入れ先・旧の名前のファイル・スタートメニューの項目は、検証機で、公開のv0.6.6を入れた上からv0.6.7の候補のインストーラーを入れて確かめました。設定の写しは最初の起動で行います（上の移行の注意）。

### 名前の変更

- 窓の題は「ERYTHEIA v0.6.7」、全画面の窓は「ERYTHEIA Fullscreen」です
- 実行ファイルは`ERYTHEIA.exe`、再生のエンジン（shim）は`erytheia_gstreamer.dll`です
- 配布物は`ERYTHEIA-v0.6.7-setup.exe`（インストーラー）と`ERYTHEIA-v0.6.7-win-x64.zip`（展開して使う版）です。インストール先は上の「インストール先」を見てください
- GStreamerのプラグインの一覧のキャッシュは、`%LOCALAPPDATA%\ERYTHEIA`に作り直します（旧の場所からは写しません）
- 旧の名前のアプリのログ（`timecodesyncplayer-*.log`）は、起動時の掃除で、最後に書かれてから31日で消します。v0.6.6までと同じく、アプリのログが1か月ほど残るようにするためです。再生のエンジンのログ（新旧の名前）は、これまでどおり7日で消します

### 表示の変更

- 操作画面を黒と赤を基調にした配色に揃え、余白・境界線・説明文を整理しました。フォントはYu Gothic UIです
- ボタンに乗せると赤の縁、押すと濃い赤になります。角は四角にし、フォーカスの枠は赤にしました。ONのボタンの緑は残しています。ONのボタンを押している間は赤になります
- 押せないボタンの地の色が暗くなりました
- 文言を短くし、元の説明はツールチップへ移しました（「📂 開く」→「開く」、「キャンバスを適用」→「適用」、「自動オフセット（…）」→「自動オフセット」、「ProRes の GPU デコード:」→「ProRes GPU:」、「Auto は確認用です。本番は固定にしてください」→「AUTO：確認用」）。オフセットの注記の行は、つまみのツールチップに移しました
- テストカードの図柄を、格子・正円・色相と階調の帯・細かさの楔・解像度の数字・8秒周期のグラデーションにしました。v0.6.6のカードにあった24ビットの更新番号は無くなりました
- **プレイリストの一覧は、一覧の中でスクロールします。** 右の欄はスクロールできるまま、一覧の高さに欄の残りの高さまでの上限を付けました。窓が十分に高ければ、一覧とその下の行が欄に収まり、一覧が自前のスクロールバーを出します。窓が低いときは一覧が最小の高さ（120）まで縮み、右の欄がスクロールします。既定の大きさの窓では、一度に見える行は1行ほどです
- 動画を開く窓と、プレイリストに足す窓の「動画」の種類から、同梱のGStreamerで開けない`.avi`・`.mkv`を外しました

### 観測の変更

- 「UI heartbeat summary」の行の末尾に、起動の1回目を除いた最大（`maxLateAfterFirstMs`）と、全体の中央値（`medianLateMs`）を足しました。前からの項目の名前と並びは変えていません
- 起動のログに、使うGStreamerの場所と出所を1行出します（`GStreamer: root=… source=bundled|env|programfiles`）
- 起動と終了の行は「=== ERYTHEIA v… 起動 ===」「=== ERYTHEIA 終了 ===」になりました
- 旧の名前の環境変数を読んだときと、新旧の両方があるときに、変数ごとに1行出します。設定を旧の場所から写したときにも1行出します

### 直した不具合

- 無し（名前の変更と表示の改修の版です）

### 既知の不具合

- 推奨素材の範囲内で既知の不具合は0件です（v0.6.6と同じ）

### 既知の制限

- 「デコードの遅れ」の警告は、UIのスレッドが描画の知らせを処理した回数で判定しています。UIの負荷が高い間は、デコードが追いついていても警告が出ることがあります。v0.6.6から同じ作りで、この版では変えていません
- アンインストールでは、アプリのフォルダの`logs`も消えます（v0.1.0からの作り）。ログを残したいときは、アンインストールの前に写してください
- 前の版のインストールの登録が無い状態で入れると、新しい名前のフォルダ（`%LOCALAPPDATA%\Programs\ERYTHEIA`）に入り、旧のフォルダ（`%LOCALAPPDATA%\Programs\TimecodeSyncPlayer`）は残ります（作りどおり）
- 同梱のGStreamerにMatroskaとAVIのdemuxは入れていないため、.mkv/.webmと.aviは開けません。推奨の容器はmp4とmovです（v0.6.6と同じ。.aviはこの版で書き足しました）
- 推奨外の形式の制限は、v0.6.6と同じです

### 既知の間欠（まれに起きる）

- v0.6.6のノートの一覧と同じです
- 開発機のE2Eで、作業中の画面の全画面がEscで閉じなかった回が、20回のうち1回ありました。アプリのログにも閉じた行が無く、原因はわかっていません
