# TimecodeSyncPlayer v0.5.6

**v0.5 系の安定版（Latest）です。** v0.5.5 の不具合を 1 件直しました。ほかの内容・既知の制限・運用の推奨は v0.5.4 と同じです（[v0.5.4 のリリースノート](v0.5.4.md)）。

v0.5.5 からの移行の注意: 無し（設定・プロジェクトの形式は変わりません）。

### 修正

- **プレイリストにファイルを足した直後（長さの読み取りが終わるまで。本数に比例して数秒〜）に一覧の行を選ぶと、読み取りの完了時に選択が再生中の行（空から足したときは先頭）へ戻ることがあった。** そのまま「上へ」「下へ」「削除」を押すと、再生中の行に効いていた。v0.5.5 以前から。
  追加の完了で選択を再生中の行へ合わせ直すのを、一覧で何も選んでいないときだけにした

### 振る舞いの変化

- 空でない一覧にファイルを足したとき、読み取りの完了で選択を再生中の行へ戻さない（選んだ行のまま）。何も選んでいないときは、これまでどおり再生中の行に合わせる

### 既知の不具合

- LTC の信号が乱れた直後に、位置を合わせ直すシークが続けて出て、重い素材（4K や 60p。H.264 でも ProRes でも）で最大 0.6 秒ほど映像が止まることがある。v0.5.4 と同じ。v0.6.1 で修正
- LTC の大きな Jump の直後に後ろ向きの位置合わせが起きた後、映像が約 1.5 秒黒になったことが検証機で 1 回あった。再走 4 回では再発せず、同じ列の再生 200 回以上で黒は他に無い。v0.5.4 と同じコード。原因は切り分け中（試験の画面の記録に別の窓が重なった可能性も残る）。v0.6.x で追う
