### 3-1. 実機確認で見つけた不具合（修正済み `148f6bf`）

1. **ライセンス文書が無言で 0 件同梱** — `package-release.ps1` のコピーが
   `Copy-Item -LiteralPath` + ワイルドカードの組み合わせでは何もコピーしていなかった。
   同梱検査（`gstreamer\share\licenses\gstreamer-1.0\LGPL-2.0-or-later.txt`）が検出。`-Path` に修正。
2. **プラグインの依存 DLL が同梱から解決されない** — `GstNative` が `tcs_gstreamer.dll` のロード後に
   `SetDllDirectory` をアプリのルートへ戻していたため、`avcodec` や `gstaudio` など `bin` 側の依存が
   PATH 経由で**システム側**から読まれていた。**このマシンに GStreamer が入っていたから動いていただけで、
   クリーンな現場では不足して再生できない**。同梱時は `SetDllDirectory` を同梱 `bin` のまま残すよう修正。

**クリーンマシン相当の再現手順（修正の確認に使用。今後の同梱確認も同じ手順で）**:

```powershell
Remove-Item Env:GSTREAMER_1_0_ROOT_MSVC_X86_64 -ErrorAction SilentlyContinue
$env:PATH = ($env:PATH -split ';' | Where-Object { $_ -notmatch 'gstreamer' }) -join ';'
Remove-Item "$env:LOCALAPPDATA\TimecodeSyncPlayer\gstreamer-registry-x86_64.bin" -Force -ErrorAction SilentlyContinue
# dist の exe を起動し、起動中にモジュールを採取（Invoke-AppGpuTrial -AppExe <dist>\... -NoFullscreen -NoSpout）
Get-Process TimecodeSyncPlayer | ForEach-Object { $_.Modules.FileName } | Where-Object { $_ -match 'gstreamer|tcs_gstreamer' }
```

期待: GStreamer 関連モジュールが**すべて `<dist>\gstreamer\` 配下**（Program Files 側 0）。
証跡: `TestResults\p1\pkg-dryrun\play4`・`modules4.json`、zip は `TestResults\p1\pkg-dryrun`、
setup.exe は `TestResults\p1\pkg-full`。
