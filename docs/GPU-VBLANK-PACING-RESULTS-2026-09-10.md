# vblank 位相基準の表示の実証結果（2026-09-10）

## 判断

[仕様](GPU-VBLANK-PACING-PROBE-SPEC.md) の `--display-pacing vblank` を実装し、実機で見つかった3つの欠陥を修正した上で、4K・fence・位相4ms・60Hz 表示先で tick と比較した。最終版（DLL `64DE9A60A34F337CE37CB33B0B661844AB89D7B5DCEC821B71A462FE9B874AD9`）の結果:

- **表示は自分の vblank 時計に従い、Present→走査が起動位相に依存せず約2.0〜2.4ms で一定になった。** 全画面 1080p と 4K 2本のすべてで表示 60Hz、refresh 連続差すべて1（表示落ち・重複なし）、表示 ID の飛び 0、窓内 notReady 0、予測誤差 −0.1〜−0.5ms、起床遅れ p99 0.6ms 以下（高分解能タイマー）。
- **一方、生成→走査（画像の総遅延）は起動ごとに 10.2／13.4／18.4ms と変わった。** 表示が vblank の直前に「その時点の最新画像」を選ぶため、合成 tick（自由走行60Hz）と vblank の位相差がそのまま画像年齢になる。tick 方式は逆に画像年齢は約0.5ms で一定だが Present→走査が起動位相で 2〜15ms 変わる（本日の tick 4本: 5.4／7.5／3.5／6.3ms、前回 14.3ms）。どちらも合計は 3〜19ms の範囲で起動依存であり、**vblank 方式が tick より短い総遅延を保証するわけではない。**
- 懸念2（表示の時計）の答え: 表示側の時計を vblank にすることは成立し、表示落ち・重複と Present 待ちの不確定性は解消した。残る総遅延の起動依存は、合成 tick の位相を vblank に整列させないと消えない。これは合成側の設計項目として次に回す（合成の周期60Hzは変えず、位相だけを表示に合わせる。Spout は合成に対する位相4ms のまま）。
- 既定は tick のまま。後続の比較基準は `fence`＋`vblank`（margin 3ms）とし、合成位相整列の実証で総遅延を判断する。

## 実機で見つけた欠陥と修正（同日）

| 欠陥 | 症状 | 修正 |
| --- | --- | --- |
| 表示期限が合成 tick のまま | 目標時刻の直後に合成期限が来る起動で、描画完了後に `present.deadline` で見送り（4K 1本で 322件、表示40Hz） | 予測 vblank 時刻を表示期限にする（bootstrap 中は従来） |
| 予測 refresh 番号で重複防止 | 統計の refresh 番号と1ずれ、次の vblank を飛ばす（1080p で2件） | vblank 時刻（半周期以上離れていること）で重複防止。番号は記録のみ |
| 合成期限優先 | 目標到達後の起床遅れ中に合成が先に走り、表示が目標より新しい画像を選んで画像 N を飛ばし N+1 を重複（4K 1本で 334件、44.8Hz） | 目標到達済みで vblank まで 1ms 以上（描画＋Present 実測 p99 0.4ms が根拠）あれば表示を合成より先に行う。合成の遅れは記録 |

各修正は管理テスト（試作 65件、解析器 109件）で固定し、解析器に `presentedIdGaps`（表示 ID の飛び）と `presentsBeforeDueCompose` を追加した。

## 限界

- 60Hz 表示先のみ。120Hz 等での挙動は未測定（DISPLAY1 を 1920×1080@120 にした比較が次の候補）。
- 予測は直近の統計から median 周期で外挿する。表示が止まる（新画像なし）と再位相合わせが遅れる。試作では毎 vblank 表示するため未発生。
- margin 3ms・lead 1ms は実測に基づく試作値で、本体の設計値ではない。
- GPU 生成画像の試作であり、mpv・CPU アップロード・本体統合は含まない。

## 次の設計項目

1. **合成位相の整列**: 合成 tick の起点を表示の vblank 位相（統計の `SyncQPCTime`）に合わせ、`target − 合成時間の余裕` で合成する。周期60Hzと Spout の位相は変えない。複数画面では1面にしか整列できないため、他画面は位相差分の年齢（最大1周期）を許容する。合格条件は生成→走査の平均が両 run で一致し 5ms 以下。
2. 120Hz 表示先での tick／vblank 比較（利用者の表示設定変更が必要）。
3. 本体契約: 表示は vblank 時計を持ち、失敗した枠は次の vblank に最新画像を出す。合成は表示に整列してよいが、Spout・他画面はそれに従属しない。
