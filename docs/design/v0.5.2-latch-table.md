## 読み方

- **現状**: 今のコードで、できごとの直後にラッチが立っているか。`Clears` = 下りている、`Keeps` = 立っている（同じできごとの中で消えて立て直された場合を含む。根拠に書く）、`NotApplicable` = ラッチを立てたままそのできごとを起こせない（理由を根拠に書く）
- **意図**: §6 の候補の行は `Clear`（**現状と食い違う行 = §6 の候補**）。できごとのコードが明示的に消している行は `Clear`（現状と同じ向き）。それ以外は `Undecided`
- **根拠**: `ファイル:行`。行番号は段 0 の時点（観測の口は各クラスの末尾に足したので、既存の行番号は v0.5.1 と同じ）
- ラッチの値は「立っている（true / non-null / 既定値でない）」か。キーは各クラスの `LatchSnapshot()`（internal）
