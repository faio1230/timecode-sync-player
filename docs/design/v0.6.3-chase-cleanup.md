### 1-2. 連鎖の読み（推定）

c₀ = 0.364（M4 のロードの遅れ）で 1 本目が +0.33 行き過ぎ → 1 本目の着地は 0.05 秒未満で学習されず c は 0.364 のまま → 2 本目も 0.364 先へ（後ろ向きなのに行き過ぎ）→ 2 本目の着地 約 0.097 秒が学習され c = 0.7×0.364 + 0.3×0.097 = 0.284 → 3 本目の行き過ぎ 約 0.18 < 許容 0.24 で止まり、残りは varispeed が拾う。間隔 0.27・0.25 秒は門 14（250ms）の間隔（2 節）

## 6. instant-rate の CRITICAL（`gst_segment_do_seek: assertion`）の整理
