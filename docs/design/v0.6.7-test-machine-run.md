# v0.6.7（ERYTHEIA）の検証機の回 — 手順書の下書き

下書き（2026-11-13）。元は設計書 [v0.6.7-erytheia.md](v0.6.7-erytheia.md) の 2.6 節（上書き・アンインストール・新規）、2.7 節（試験の基盤と 1 回にまとめた送付）、4 節（検証機の未完）、5 節（順と量）。食い違ったときは設計書を正とし、この手順書を直す。

検証機の回は、名前の変更の段 2 の後に **1 回でまとめて** 行う。利用者の希望「テスト周りは一回で終えられるよう確認してから」に合わせ、始める前に事前の確かめを全部通してから進める。途中で事前の条件が崩れたら、その場で止めて親へ 1 行で知らせる。

## 0. 利用者が手で行うこと

検証機の担当が自動で進められないものを、ここに 1 か所にまとめる。担当は、この順で利用者に頼む。

| 順 | いつ | 利用者が行うこと |
|---|---|---|
| 1 | 送付を受けた後 | この回を始めてよいという許可（試験用 ffmpeg の版の固定のパッチを当てることを含む） |
| 2 | 事前の確かめの前 | 検証機にコンソールでログオンする（リモートデスクトップで入らない） |
| 3 | 事前の確かめで止まったとき | UAC の確認の窓や、前面に出た他の窓を閉じる。空きが 4 GB に足りなければ、常駐のプログラムの終了などで空ける |
| 4 | 上書きの回の前 | まっさらな環境の利用者（検証用のアカウント）でログオンする |
| 5 | 上書きの回 | v0.6.7 の setup を実行する（UAC の確認があれば許可する） |
| 6 | 記録だけの回 | v0.6.6 を起動したまま setup を実行する（下の 3.3） |
| 7 | アンインストールの回 | 「アプリ」の設定から ERYTHEIA をアンインストールする |
| 8 | 新しく入れる回 | 消すフォルダ（下の 5）を担当と確かめてから消し、v0.6.7 の setup を実行する |
| 9 | 終わった後 | まっさらな環境の利用者からログオフし、元の利用者に戻る |

## 2. 事前の確かめ

始める前に全部を確かめ、1 つでも満たさなければ進めない。無効な回を数分で止めるための確かめで、満たさないまま流した結果は合否に使わない。

| 項目 | 期待 | 確かめ方 |
|---|---|---|
| ディスクの空き | 4 GB 以上 | ドライブの空きの値を記録 |
| UAC と前面の窓 | consent.exe が 0 個。試験の窓より前に他の窓が無い | プロセスの一覧、前面の窓の題 |
| 画面のセッション | console のセッションで動いている（リモートデスクトップではない） | query session の出力 |
| 主ディスプレイ | 1920×1080、60Hz | ディスプレイの一覧の出力 |
| GPU | 外付けの GPU の adapterLuid で起動する（内蔵の GPU ではない） | アプリのログの adapterLuid の行を、GPU の一覧の LUID と突き合わせる |
| shim の SHA | 下の 6 の 3 か所で同じ | SHA の一覧 |

## 3. 上書きの回（v0.6.6 → v0.6.7）

まっさらな環境の利用者で行う。

### 3.1 上書きの前に確かめること

| 項目 | 期待 | 確かめ方 |
|---|---|---|
| 新しい設定の場所 | %LOCALAPPDATA%\ERYTHEIA が無い | フォルダの有無 |
| 旧のアプリのログ | 最終書き込みが 8 日より前の timecodesyncplayer-*.log がある | logs のファイルの一覧（最終書き込みの日時つき） |
| 入っている版 | v0.6.6 が入っている | 窓の題「Timecode Sync Player v0.6.6」の PNG、インストール先の exe の一覧 |

### 3.2 上書きの後に確かめること

**見ただけの合格にしない。** どれも、アプリのログの Information 以上の行、ファイルの一覧、PNG のどれかで示す。

| # | 項目 | 期待 | 示すもの |
|---|---|---|---|
| 1 | 入れ先 | 実測で記録する（前の場所か Programs\ERYTHEIA か）。Inno Setup の既定の振る舞いの推測なので、どちらでも記録し、設計書の想定（前の場所のまま）と違えば親へ返す | ファイルの一覧 |
| 2 | 旧の exe・shim・ショートカット | 旧の TimecodeSyncPlayer.exe、旧の shim、スタートメニューの旧のショートカットが残っていない。ショートカットは 1 つ | ファイルの一覧 |
| 3 | 設定の引き継ぎ | 新しい場所に写され、値が同じ。旧の場所も残る | 写した旨の Information の行。両方の settings.json の有無。画面のオフセットと fps の PNG |
| 4 | 旧のアプリのログ | 8 日より前のものも残っている。新しいログは erytheia-*.log | logs のファイルの一覧（最終書き込みの日時つき） |

## 7. 合否の一式

設計書の 5 節の順の 6（候補）の検証機の分:

- 固定の一式（標準 3、L-1 6、A の切替、RTX）
- AMD 内蔵の GPU でテストカードと再生を 1 回
- まっさらな環境の上書き（3）・アンインストール（4）・新規（5）
- shim の確かめ（6）

実素材を使う回は M1〜M7 で呼ぶ。実素材と、そこから切り出したフレームは検証機から出さない。数値だけを返す。
