# V3 合格基準の書き直し（案）

状態: **案。利用者の承認待ち。** 作成 2026-09-15、親。
**数値は親が独断で決めない。** 下記は実測に基づく提案であり、現場要件に照らして利用者が決める。

---

## 1. なぜ書き直すのか

現行の基準は前提が 3 つとも変わった。

| 現行の基準 | 変わった前提 |
| --- | --- |
| 定常誤差が **mpv×Gpu と同等以下** | **mpv は v0.4 で削除する。** 比較対象が消える |
| シーク回復 **p95 250ms 以下** | **出荷中の mpv 自身が満たしていない**（実測 最大 1066ms）。基準が現場要件より厳しい |
| （速さだけを見る） | 利用者の指示: **ジャンプが若干遅れるのは可。落ち着いた先の精度を重視** |

利用者の指示（2026-09-15）:

> mpv は削る前提であるので、GStreamer だけ基本的に見ればいい
> 現場基準で考えたときの ms で測るのがベスト
> シークの追従が若干ジャンプが遅れるのはいい。デコードの物理的な限界速度があると思うので

## 2. 測定の前提（基準とは別に固定する）

- **対象は GStreamer × GPU 合成のみ**（`backend=1` / `outputBackend=1`）
- **`SyncOffsetMs = 0`** で測る。オフセットは現場の調整手段であって精度を作る手段ではない
- **先行補償（D7-a）は無効**のまま
- **LTC 4 種（24 / 25 / 29.97 / 30）すべてで満たすこと**
- 29.97 は**手動指定**（`Fixed29_97`）。自動検出が 30 と誤るのは既知で、マニュアルに記載する
- **この測定に LTC 入力遅延（40〜90ms）は含まれない。** 現場ではその分が上乗せされ、
  `SyncOffsetMs` で吸収する（`docs/SYNC-ACCURACY.md` 参照）

## 3. 基準の案

### 主基準: 定常誤差（落ち着いた先の精度）

**各フェーズの平均誤差の絶対値 ≤ 40ms**（settling を除く、全 LTC fps、全クリップ）。

根拠:

- **現在の連続再生は -34〜-45ms**（LTC 4 種で安定）。T5 で改善が見込める
- T5 の**デッドバンド初期値が 20ms** なので、収束先は ±20ms 前後。測定の粗さを足して 40ms
- 参考: 1 フレームは 30fps で 33ms、24fps で 42ms。**約 1 フレーム相当**

### 副基準: ばらつき

**プールした p95-p5 ≤ 100ms**（現在 151〜175ms）。

根拠:

- **フェーズ内のばらつきは 50〜68ms** で、これは素材のフレーム量子化そのもの
  （24fps の 1 フレーム = 42ms）。**これ以下には原理的にならない**
- 現在の 151〜175ms は「連続再生とシーク後の**フェーズ間の差**」が乗っているため。
  T5 が効けばフェーズ内のばらつきに近づく。100ms は余裕を見た値

### 副基準: 収束時間（**250ms の絶対予算は撤廃**）

**シーク・トラック切替から 2 秒以内に、上記の定常誤差へ入ること。**

根拠:

- 利用者の指示で**ジャンプの遅れ自体は許容**。デコードの物理限界がある
- T5 の `Smooth` は ±10% なので **150ms を 1.5 秒**で詰められる
- **「速く落ち着く」ではなく「確実に落ち着く」を見る基準**に変える。
  現行基準は落ち着いた先で 100ms 以上正確な方を落としていた

### 維持: ギャップ再入

**p95 500ms 以下**（現行のまま）。GStreamer は実測 最大 152ms で余裕がある。

### 追加: 発振しないこと

- **`Smooth` ではシークを 1 回も発行しない**
- `Jump` では補正シークが**連続 3 回を超えない**
- `seek.decide` が 2 秒間隔で繰り返し出続けない

## 4. この案で現状はどう判定されるか（T5 前）

| 基準 | 現状（T5 前） | 判定 |
| --- | --- | --- |
| 定常誤差 ≤ 40ms | 連続再生 -34〜-45ms、**シーク後 -42〜-157ms** | **シーク後が未達** |
| ばらつき ≤ 100ms | 151〜175ms | **未達** |
| 収束 2 秒以内 | 収束しない（補正手段が無い） | **未達** |
| ギャップ再入 500ms | 最大 152ms | **合格** |
| 発振なし | 発振なし | **合格** |

**T5 が入って初めて上 3 つに届く見込み。** T5 の実機測定で確かめる。

## 5. 決めていただきたいこと

1. **定常誤差 40ms でよいか。** 現場で許容できるずれの大きさ。
   1 フレーム相当を目安に置いたが、LED ウォールでの見え方によっては緩くも厳しくもできる
2. **ばらつき 100ms でよいか。** フレーム量子化で 50〜68ms は原理的に残る
3. **収束 2 秒でよいか。** これより短くするとレート偏差を上げる必要があり、
   音のピッチ変化が大きくなる（±10% で約 165 セント）
