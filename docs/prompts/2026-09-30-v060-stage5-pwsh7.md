# 指示書: v0.6.0 段 5 スクリプトを PowerShell 7 に寄せる

担当: サブエージェント A。作業ツリー `timecode-sync-player-v053`、ブランチ `agent-a-v060`（`v0.6.0` の先頭まで進めてある）。
設計書: `docs/design/v0.6.0-prores-gpu.md`（7 節の段 5 と「段 5 の前提と追加点」）、`docs/release-0.6-plan.md` の「スクリプトを PowerShell 7 に寄せる」の節、`docs/GOAL-v0.6.md` の v0.6.0 の行。先に読むこと。

## 決まっていること

- **v0.6.0 以降のブランチのスクリプトだけ**を 7 に寄せる。0.5 系（hotfix 用）は 5.1 互換のまま（TSP-Fable の決定 2026-09-30。このブランチの作業には関係しないが、0.5 系のブランチには触らない）
- 開発機・検証機とも PowerShell 7.6.6（Microsoft Store の MSIX 版）。`pwsh` は**コマンド名で**呼び、絶対パスを埋め込まない（`Program Files\PowerShell\7` は無い）

## 範囲

1. **一覧を先に作る**: git 管理下の `.ps1`（33 本）について、5.1 向けの回避の箇所をすべて一覧にして報告の最初の節に書く（ファイル:行、回避の種類、外すか残すか）。種類の例: BOM・ASCII のみの注意書き、`UTF8Encoding($false)`、`2>&1` と NativeCommandError の回避、`$PSScriptRoot` の param の既定値の手当て、`&&`・`||` を使わない書き方、三項演算子・null 合体の代わり、`ConvertFrom-Json -AsHashtable` の代わり、`Invoke-WebRequest -UseBasicParsing`、TLS 1.2 の明示、空文字の引数が落ちる件、ワイルドカード展開の件。**外すのは 7 で不要になると確かめたものだけ**。挙動が変わるもの（エンコーディングの既定が変わるなど）は、外した結果の出力のバイトが同じになるかを確かめてから
2. **`#requires -Version 7.0`** を全 `.ps1` の先頭に付ける（BOM の後）。5.1 で実行すると読み込みの時点で止まることを 1 本で確かめる
3. 回避を外す（1 の一覧で「外す」にしたものだけ）。ファイルの文字コードは UTF-8（BOM の有無は既存に合わせてよい。7 は BOM なしの UTF-8 を正しく読む）、改行は CRLF のまま
4. **スクリプトからスクリプトを呼ぶ箇所**（`powershell -File …`・`powershell.exe`）を `pwsh` に。試験の C#（`tests/`）やアプリ（`src/`）がスクリプトを起動している箇所があれば同じく（無ければ報告に「無し」）
5. **文書**: `docs/SETUP.md` に PowerShell 7 を要件として書く（`winget install Microsoft.PowerShell`）。5.1 で実行したときのエラー（`#requires` で止まる、そのときの表示の例）の読み方を 1 行。文書の `powershell -File` を `pwsh -File` に（`docs/` の中の、v0.6.0 の手順として使う文書だけ。過去の記録・報告・設計書の履歴の文は書き換えない。`CLAUDE.md` のビルド手順と `RELEASE-PROCEDURE-0.4.md` の手順は書き換える）

## してはいけないこと

- push、`main`・`v0.6.0`・0.5 系のブランチへの書き込み、stash・reset・clean
- 実機の試験（アプリの起動、E2E、LTC シナリオ、ランナーの本番の実行）。`run-ltc-scenarios.ps1 -PreflightOnly` も実機の音声の装置を見るので**回さない**（親が回す）
- 製品のコード（`src/` の C#、`native/gst-shim/src`）の変更（4 で起動の箇所がある場合だけ可）
- 素材の作品名・ローカルの絶対パス（利用者名）をコミットするファイルに書くこと

## 完了の条件

- 全 `.ps1` の構文検査を `pwsh` の Parser で 0 件（`[System.Management.Automation.Language.Parser]::ParseFile`）
- **空振りの実行**: 各スクリプトを、副作用の無い呼び方（`-?`、`Get-Help`、または引数の検査で止まる呼び方）で `pwsh` から 1 回ずつ。実機・ダウンロード・素材の生成が要るものは、その手前で止まる呼び方を選び、選んだ呼び方を報告の表に書く
- 実際に動かして確かめるもの（副作用が作業ツリーの中だけで済むもの）: `get-prores-plugin.ps1`（キャッシュの照合）、`native\gst-shim\build-shim.ps1`（Debug）、`package-release.ps1 -SkipInstaller`（zip まで。できたら退避の名前に改名）、`make-e2e-media.ps1`（出力先を作業ツリーの一時フォルダに）。どれも `pwsh -File` で
- 5.1 で `#requires` により止まることを 1 本で確かめる
- 改行が CRLF のままであること、制御文字が紛れていないこと（`\t` などのエスケープを文字列に入れて書かない）
- 非E2E が全件合格
- 日本語のコミット（回避の種類ごとか、スクリプトの群ごと）
- **終わったら、そのツリーでビルドやファイルの書き換えをしない**
