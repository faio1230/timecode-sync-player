## 再現した不具合

1. Gapから別動画に入る最初の有効LTCで、前の動画へシークしてから処理を終了していた。次の有効フレームが来ないと動画切り替えが残る。
2. Freeze取得中の早期終了により、Blackへの変更や新しいOnTrack判定が遅れる。保留取得と古い描画を取り消す必要があった。
3. 設定変更時に最後の有効LTCを再評価せず、LTC停止中にBlack/Freeze、Single/Continue、Sync ONの変更が反映されない。Gap自身の停止を手動解除時に戻す経路も不足していた。
4. 空プレイリストで既存Gap状態を早期終了するため、Black/Freeze変更を反映できない。
5. 実動画のロード安定化やシーク待ちの間に最後の同期要求が失われる。TC290.80でBをロード直後、440.28へ飛ばして止めると、期待する動画内149.513秒に対して6秒待っても約6.68秒だった。曲名だけの検査では見逃していた。
6. 位置指定ロードがmpvの停止状態を放置し、UIだけ再生中へ更新する。前の停止やEOFの停止が残ると映像は静止したままになり、次の同期要求もロード待ちで約5秒保留される。位置指定ロードでは現在の停止意図を実エンジンとUIの両方へ適用する。
7. SingleでEOFへ進んでから5秒へ巻き戻すと、位置だけ戻って静止する。実機で6秒待っても5秒のままになることを再現した。絶対/相対シーク成功後にも停止意図を実エンジンへ適用し、利用者が止めていれば停止を保つ。

新しい有効LTCとして扱う処理と、設定変更による再評価を分ける。再評価で受信時刻や信号回復回数を増やさず、利用者の停止・信号断による停止・手動シークを尊重する。ロード/シーク失敗時はGap状態と停止所有権を失わず再試行する。

保留要求は最新1件だけを保持し、成功・不要時に消費する。完了後に古い位置へ引き戻さない。手動シークはシークバー、±10秒、タイムラインの各入口で取り消す。先行するnativeシークが残っている場合は、現在位置が一時的に許容内でも最新要求を消費せず、先行操作が終わってから再判定する。

## 再実行

Windowsの操作可能なデスクトップ、PowerShell 7.2以降、Debugビルド環境、mpv DLL、ffmpeg、VB-CABLE、上記動画が必要。このPCでは準備済み。試験中はPCをロック・スリープさせず、対象アプリを操作しない。

```powershell
./scripts/run-timecodesyncplayer-real-project.ps1 -ProjectPaths `
  'C:\Users\<user>\Videos\20260518_test.tsp', `
  'C:\Users\<user>\Videos\20260518_test_2.tsp'
```

LTCは25fps、VB-CABLEは48kHz/stereo。各境界を挟む25fpsフレームを送出し、選択トラックと動画位置を確認する。ブラックは映像領域の画素も検査する。終端まで余裕のある区間では出力を止め、最後の要求位置を0.3秒超えてからさらに0.15秒進むことも確認する。保留シークの到達だけで再生中と誤判定しないためである。

設定切り替え前にもLTC出力を停止し、受信待ちを消化する。モード変更後の診断リセットが次の重複フレームを新規受信扱いすることで、即時反映の失敗を隠さないためである。

元動画の終端は黒い場合があるため、同じ実素材Aを結果フォルダへコピーし、10秒でトリムした派生プロジェクトを作る。Black→Freezeの非黒画素、終端への移動、静止、Blackへの復帰を確認する。この視覚検査は上記2件に含まれる`Substitute_A`を前提とし、各回約88MBの素材コピーが残る。

通常のテストではRealProject分類はスキップする。明示実行時はスキップ・結果欠落・強制終了を成功としない。既定の総時間上限は各プロジェクト3分、履歴の無更新は60秒で失敗。停止対象は自身が起動したプロセスであり、アプリのID・開始時刻・EXEを照合する。

`TestResults/real-project/<日時とID>/`に集計とバイナリハッシュ、各プロジェクトの履歴、画像、派生fixture、テスト結果、アプリログ追記分、監視結果を残す。ERR/FTLログも失敗とする。元.tspのSHA-256を前後で照合する。素材・元プロジェクト・画面画像はコミットしない。

## 検証範囲

論理境界テストは終了直前と終了時刻の区別を含む。実機位置検査は非同期ロード・UI更新を含めて6秒以内に期待位置との差1秒未満となることを確認するもので、1フレーム精度や本番で許容できる最大応答時間の保証ではない。25fps以外のLTC、本番時間の連続負荷、音声デバイス無効化/復帰、Spout受信映像は別途検証する。
